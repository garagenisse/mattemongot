"# Mattemongot

**Practice multiplication tables!** A fun math game for learning times tables 1-20.

## Description

Mattemongot is an educational app designed to help children and adults practice multiplication tables. Originally created by garagenisse, this version has been upgraded to modern Ionic 8 with Angular and Capacitor.

## Features

- Practice times tables from 1 to 20
- Timed mode with progress tracking
- Earn stars (bronze, silver, gold) based on performance
- Multi-language support (English, Swedish)
- Works on web, Android, and iOS

## Technology Stack

- **Framework**: Ionic 8
- **Frontend**: Angular 18
- **Mobile**: Capacitor 6
- **Language**: TypeScript
- **Styling**: SCSS

## Getting Started

### Prerequisites

- Node.js 20+
- npm 10+

### Installation

```bash
# Install dependencies
npm install

# Run in development mode
npm start

# Build for production
npm run build
```

### Adding Mobile Platforms

```bash
# Install Capacitor CLI
npm install -g @capacitor/cli

# Add Android platform
npx cap add android

# Add iOS platform
npx cap add ios

# Sync web build with native platforms
npx cap sync
```

### Running on Mobile

```bash
# Open Android project in Android Studio
npx cap open android

# Open iOS project in Xcode
npx cap open ios
```
